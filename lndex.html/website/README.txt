AromaCraft Artisan Coffee — CSS modules

Files:
- main.css: main entry point; import this file from your HTML.
- 01-variables.css: colour, typography, spacing, radius, shadows and transitions.
- 02-base.css: CSS reset, global body styles, container and section defaults.
- 03-typography.css: headings and section headers.
- 04-buttons.css: button styles and interaction states.
- 05-header.css: sticky header, logo and navigation.
- 06-hero.css: hero banner and its content.
- 07-about.css: about section and value cards.
- 08-products.css: product/menu cards.
- 09-multimedia.css: embedded and local video styles.
- 10-testimonials.css: testimonial cards.
- 11-contact.css: contact information and form.
- 12-footer.css: footer layout and links.
- 13-responsive.css: tablet and mobile media queries.

Usage:
Use main.css as the only stylesheet link in your HTML:

<link rel="stylesheet" href="css/main.css">

Keep all 13 module files in the same folder as main.css. The relative
background image path in the original CSS remains assets/images/hero-bg.jpg.
